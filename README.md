# Bella Tavola Restaurant 🍝

A restaurant page project built as part of **The Odin Project JavaScript curriculum**.

## Live Demo

🔗[View Live Demo](https://hadiswebpro.github.io/odinrestaurant/)


## About The Project

Bella Tavola is a fictional Italian restaurant website created to practice modern JavaScript development concepts.

The entire website content is dynamically generated using JavaScript modules instead of writing the page content directly in HTML.

## Features

- Dynamic page rendering with JavaScript
- Home, Menu, and Contact pages
- Tab-based navigation
- DOM manipulation
- ES6 Modules (import/export)
- Webpack bundling
- Responsive design
- Custom restaurant theme and layout
